# Homebrew Tap for Centsible 🪙⚡

Official Homebrew Tap for [centsible](https://github.com/ntrieuvi97/centsible).

## Installation

```bash
brew tap ntrieuvi97/tap
brew install centsible
```

Or install in a single command:

```bash
brew install ntrieuvi97/tap/centsible
```

## Verify

```bash
centsible --version
centsible status
```
